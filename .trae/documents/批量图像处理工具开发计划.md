# 批量图像处理工具开发计划

## 1. 项目概述

**项目名称**: ImageBatchProcessor
**项目类型**: 桌面应用程序 (FFmpeg + PySide6 + 多线程)
**核心功能**: 批量图像格式转换，支持单张处理和批量处理
**目标用户**: 需要频繁进行图像格式转换的用户

## 2. 功能需求

### 2.1 核心功能
- 支持单张图像格式转换
- 支持批量图像格式转换
- 支持拖拽添加文件
- 支持多种输出格式 (PNG, JPG, WEBP, BMP, TIFF, GIF, TGA, PSD 等)

### 2.2 格式支持
基于 FFmpeg 的图像格式支持：
- **输入**: PNG, JPG/JPEG, WEBP, BMP, TIFF, GIF, TGA, PSD, EXR, HDR 等
- **输出**: PNG, JPG/JPEG, WEBP, BMP, TIFF, GIF, TGA

### 2.3 用户界面
- 现代简洁风格
- 文件列表显示区域
- 输出格式选择下拉框
- 单张/批量处理切换
- 进度条显示
- 实时日志输出
- 输出目录选择

## 3. 技术方案

### 3.1 技术栈
- **GUI框架**: PySide6 (Qt for Python)
- **图像处理**: FFmpeg (通过 subprocess 调用)
- **多线程**: ThreadPoolExecutor (concurrent.futures)
- **打包工具**: PyInstaller (可选)

#### Worker (core/worker.py)
```python
class ConversionWorker(QThread):
    progress_changed = Signal(int, int)  # current, total
```

## 6. FFmpeg 图像转换命令参考

```bash
# PNG 转 JPG
ffmpeg -i input.png output.jpg

# PNG 转 WEBP
ffmpeg -i input.png output.webp

# 质量控制 (JPG)
ffmpeg -i input.png -q:v 2 output.jpg

# 缩放
ffmpeg -i input.png -vf scale=800:-1 output.jpg
```
